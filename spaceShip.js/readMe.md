
# 🚀 SpaceShip Defender

A fast-paced space shooter built with vanilla JavaScript and HTML Canvas.
Defend your ship against waves of enemy attackers, survive as long as possible, and climb the scoreboard.

**[Play the game](https://nzevgolisda.github.io/spaceShip.js/)**

## Features

- 🎮 Smooth keyboard controls (Arrows / WASD + Space to shoot)
- 👾 Three enemy types: Basic, Fast, and Tank
- 📈 Dynamic difficulty scaling with score
- ✨ Particle effects & visual polish
- ❤️ Lives system with invincibility frames

## How to Play

- **Move:** Arrow keys or WASD
- **Shoot:** Spacebar or F key
- **Goal:** Destroy enemies, avoid collisions, survive!

## Tech Stack

- Vanilla JavaScript (ES6 Classes)
- HTML5 Canvas
- CSS3 with Glassmorphism UI
